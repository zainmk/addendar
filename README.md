# addendar

### purpose
a google chrome extension that allows users to add Google Calendar events using AI to parse screenshots/text.

### stack
HTML, JS, CSS, GOOGLE CHROME EXTENSION

### setup / use
- obtain your api key
- clone the repo, go to google chrome extensions and load an unpacked extension. select the cloned directory.

### notes
- the chrome extension is not in the store yet (run locally, unpacked)

### API Keys
- Anthropic API Key: You will need an Anthropic API Key to 'fuel' the parsing of screenshots/texts.
